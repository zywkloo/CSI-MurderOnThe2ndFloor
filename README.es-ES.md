# Investigador de Escenas del Crimen - cuHacking 2020
* [GANADOR de Murder on the 2nd Floor](https://devpost.com/software/murder-on-2nd-floor-web-forensic-analyzer)  [[Martello](https://martellotech.com/)]
* Restaurar escenas del crimen con alta fidelidad en las dimensiones de tiempo y espacio para ayudar a analizar sospechosos!

## Inspiración
[Desafío de Análisis Forense de Datos de Martello](https://martellotech.com/cuhacking/)

![](https://github.com/zywkloo/CSI-MurderOnThe2ndFloor/blob/master/backup/MurderOnThe2ndFloor_%20cuHackingChallenge_Martello.png?raw=true)

## Qué hace
Una herramienta para ayudar al equipo forense a simular escenas del crimen y analizar a los sospechosos mediante su comportamiento basado en el tiempo y el espacio.

## Cómo la construimos
Aprovechamos al máximo la tecnología web moderna como `Plotly.js`, `Node.js`, y`Express` para construir un analizador que restaure la escena del crimen con alta fidelidad.

## Desafíos que enfrentamos
* Ninguno de nosotros tiene experiencia en la biblioteca de visualización.

## Logros de los que estamos orgullosos

* Una aplicación que puede usarse para investigar la escena del crimen.

<img src="https://github.com/zywkloo/CSI-MurderOnThe2ndFloor/raw/master/backup/FileUploader.gif" width = "50%"  alt="2" align=left />

 ### Tres Características Clave

* Subidores: 
  * Permite subir archivos JSON (por ejemplo, Murder-on-the-2nd-Floor-Raw-Data.json) para analizar los datos de todos los sospechosos. 
  * El usuario podría designar la escena del crimen (habitación #).
Esto se adapta a usuarios con requisitos analíticos dinámicos.

<img src="https://github.com/zywkloo/CSI-MurderOnThe2ndFloor/raw/master/backup/CrimeScene.gif" width = "50%"  alt="2" align=right />

* Visualización de líneas de tiempo: Una aplicación web de visualización muestra el comportamiento de todos los sospechosos según la línea de tiempo en el plano 2D del edificio.

* Visualización espacial: Basado en la habitación del asesinato ingresada por el usuario, la frecuencia de ocurrencia de todos los sospechosos se marcaría en la caja 3D.

 ### Resultado
* En lugar de ofrecer una conclusión basada en datos específicos dados, ofrecimos una herramienta de visualización de datos para ayudar al usuario (la policía, el analista) a formular su juicio. 

## Lo que aprendimos
- Aprendimos cómo discutir un problema desconocido con compañeros de diferentes fondos de programación.
- Aprendimos cómo modificar la biblioteca de visualización de datos para cumplir con nuestro propósito
